## 浏览器检查

- 从 R1 对方发球开始，我方得分切至 R2 并显示我方发球队员。
- 我方连续得分维持 R2；对方得分转为接发且仍为 R2。
- 查看 R3 不改变真实比赛 R2，所有加减分按钮锁定；可返回当前轮。
- 刷新后恢复 2:1、R2 及对方发球。

- 手机尺寸下检查单字圆圈、比分及并排轮次小图；未发现横向溢出。
- 停止本地 HTTP 服务（curl 连接失败）后重新加载，仍显示已恢复比赛，证明 Service Worker 能独立提供缓存页面。

## 2026-10-21 界面与使用流程复核

九条反馈均落实：淡青球场；删除欢迎语；加减分等大带填充；删除固定“自由训练”；大小场地顶部对齐；去掉球网/前场/后场文字并保留边线与三米线；当前轮次标题；恢复按钮仅编辑时出现；调整与换人置于球场上方。

浏览器验证使用本机测试数据，未修改线上用户数据：
1. 赛前：记分板收起、恢复按钮隐藏、轮次切换可用。选 R3 后打开开始设置，起始轮次为 R3。
2. 编辑：键盘移动及指针拖动有效；恢复需要确认，确认后仍保持编辑；完成后刷新保留坐标。
3. 记分：R3 接发得分后为 R4；减分不改变轮次；撤销恢复比分。
4. 查看其他轮：显示查看轮/实际轮，记分和换人禁用；返回当前轮恢复。
5. 校正：设置 R2 和对方发球后正确显示；旧撤销清空。
6. 换人：无替补时可直接添加且确认禁用；添加陈明后自动返回，换人及换回正常，轮次和站位不变。
7. 退出：可选覆盖/不覆盖；覆盖后修改坐标成为默认，记分板收起。
8. 手机 375px：页面宽 375px；四个加减按钮均 67×44px；大小球场顶部同为 440.015625px；编辑工具无横向溢出。桌面预览也完成检查。

限制：浏览器验证不替代 iOS 真机触控与辅助功能全面测试。核心与分享测试 28 项通过。

## 手机版方案落地（2026-10-21）

- 所有屏幕保持手机单列，最大宽 480px；移除桌面双栏与重复底部导航。顶部为队员、分享入口。
- 统一浅灰背景、白色比分板、浅蓝灰球场。球场半场为正方形，保留蓝紫前后排识别。
- 比分板压缩高度，发球与实际轮次并列；加减按钮等大，加分使用蓝色填充。
- 站位编辑提供恢复、取消调整、完成。拖动暂存在内存，完成或切换功能面板时保存；取消恢复进入编辑前的坐标。
- 修复编辑时打开说明后，编辑标签及禁用记分未同步的问题。
- 比赛设置首发两列，从已有比分开始可展开；输入文字不低于 16px，减少 iPhone 聚焦缩放。

验证：28 项核心与分享测试通过。浏览器验证取消、完成后刷新、恢复后继续编辑、取消恢复、关闭说明回到记分、预览轮次禁用记分/撤销/换人、返回记分、生成分享链接均正常，控制台无错误。

375 / 390 / 430px：页面宽度与视口一致，按钮均高 44px、四个按钮宽度分别均为 69.75 / 73.5 / 83.5px。大小球场顶边一致，正常比赛时图例底部分别为 746.30 / 761.30 / 801.30px，可在 844px 视口中同时看到比分与完整球场。

效果：[新版比赛界面](design-review/05-mobile-match.png)。旧界面与设置审查留存在 design-review/；04 为整理期间的设置截图，最终仅按手机版交付。未做 iOS 真机验证。
