# 排阵手机版设计复核

目标：手机场边快速确认比分、发球权、轮次与接发站位，完成记分、换人及临场调整。

原版优点：范围集中、站位图简洁、前后排虚线及自由人填充可辨。原版问题：头部与底部导航重复、记分与站位操作主次不清、表单过长；编辑状态进入说明后没有同步刷新，可复现记分保持禁用。

1. 赛前入口：已简化，队员与分享在顶部；主入口直接开始比赛。正常。
2. 比赛设置：首发两列，非零起始比分可展开。正常。
3. 记分：发球与实际轮次靠近比分，加减等大，撤销在比分板。正常。
4. 查看其他轮：查看轮与实际轮区分，暂停记分/撤销/换人；可一键返回。正常。
5. 编辑：恢复、取消、完成分开；取消还原，完成后刷新保留；离开编辑刷新可用状态。正常。
6. 分享：链接生成正常，保持只复制与粘贴链接。正常。

视觉：手机单列、浅灰背景、白色比分板、浅蓝灰球场、蓝色主按钮；只用蓝紫区分前后排。控件至少 44px 高，队员仍是 30px 圆圈加 44px 触控范围。比分有 live region，轮次与编辑切换保留键盘焦点。
